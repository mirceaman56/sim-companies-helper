Installation

  1. Download the latest .zip release.
  2. Go to chrome://extensions in your browser.
  3. Enable Developer Mode at the top right.
  4. Drag and drop the zip file or click Load Unpacked.

What it does

  • Displays real-time profit per minute for retail products
  • Shows the cheapest market listing
  • Calculates your cost basis automatically
  • Full production analysis including transport costs
